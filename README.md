# Quralyt

**Quralyt** is a Quran reading app focused on clarity, spiritual peace, and complete offline access.  
It is part of the Lytdesign ecosystem, built to deliver distraction-free Islamic experiences for all ages.

---

### 🌟 Features

- Mushaf-style and vertical scrolling options
- Clean UI with yellow-on-black night mode
- Offline reading with Surah downloads
- Dedicated Tafsir & Translation sections
- No ads. No trackers. Just the Qur’an.

---

### 🧠 Philosophy

> “Design should serve the soul.”  
Quralyt is designed to support focused Quran reading, without modern digital clutter. The app reflects a commitment to spiritual usability, privacy, and free access.
